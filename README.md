# 🧪 Desafio Técnico – Cypress (UI + API)

Projeto de automação de testes para e-commerce utilizando Cypress, cobrindo fluxos **UI (Web)** e **API**, com foco em boas práticas, organização e escalabilidade.

---

## 🚀 Tecnologias

- Cypress
- Cucumber (BDD)
- JavaScript
- Faker
- Page Object Model (POM)

---

## 🌐 Sistema testado

https://www.automationexercise.com

---

## ✅ Cenários

### 🖥️ UI (Web)

- Cadastro de novo usuário
- Validação de login
- Busca do produto *Men Tshirt*
- Captura de nome e valor
- Adição ao carrinho
- Validação de produto e preço no carrinho

---

### 🔌 API

- Criação de usuário via `POST /api/createAccount`
- Validação de:
  - Status code **201**
  - Mensagem `"User created!"`
  - Estrutura da resposta
